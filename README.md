Triagem e Extração de Metadados de Petições Iniciais.

Este projeto é um script em Python desenvolvido para auxiliar na triagem inicial de petições jurídicas.

A ideia é analisar o texto da petição e extrair as principais informações de forma estruturada, como as partes envolvidas (autor e réu), o ramo do direito, o tema principal da ação, as teses abordadas e os pedidos formulados. 

O script processa o texto identificando padrões e palavras-chave, retornando os dados organizados em formato JSON. O projeto foi desenvolvido em Python 3 utilizando apenas bibliotecas nativas como re e json.
